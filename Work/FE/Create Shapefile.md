1. Go to server → select ADT
2. Select `Heritage_ADT` → select `Integrated Heritage Management` (polygon map server)
3. Right click and click `add layer to project`
4. ![[Pasted image 20241210104457.png]]
5. Right click on the layer to view attribute table 
6. After importing the layers, we can now create a shapefile
7. select `Layer` → `Create layer` → `New Shapefile Layer`
8. Create a new folder to save the shapefile 
9. Geometry type has to be polygon 
10. and coordinates should be this 
11. ![[Pasted image 20241210110740.png]]
12. Once pressed Ok we can see our shapefile added as a new layer
13. Right click on the shapefile layer and select `Toggle editing`
14. Click on `Add polygon` → draw the polygon where you want it to intersect or not intersect
15. right click to exit drawing then enter attribute
16. to change he color select styles and select edit symbol to change the shapes color and opacity
17. ![[Pasted image 20241210111338.png]]
18. click on `Save layer edits` to apply the new changes 
19. we can now go to the folder where we saved the shapefile and create a zip file and copy the files into it 
20. once zip file has contents we can now use it in our application
