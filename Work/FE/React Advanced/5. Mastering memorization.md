useMemo/useCallback under the hood?
- useCallback always returns back the same reference 
	- its a pre-defined function that accepts another function as the first argument 
- useMemo functions the same way as callback but this time I return the value I want to memoize 
what is a hook?
- a hook is just a function that React calls for us 
- every hook is called on every re-render 
Memoization props as anti-pattern?
- memoizing props prevents components from re-rendering which is false
- 2 major useCases when we actually need to memoize props on a component
	1. when the prop is used as a dependency in another hook in a downstream component otherwise if a re-render is triggered on this level, the components hook will be triggered unnecessarily
	2. when a component is wrapped in React.Memo
		- allows us to memoize the component itself between re-renders
		- usefulness is very limited if a component is wrapped in React.Memo, and its re-render is triggered by the parent and only by the parent, then react won’t re-render the memoized component 
			- if the component has props then react will check if the props have changed before making the re-rendering decision

USEMEMO is ONLY USEFUL FOR RE-RENDERS

IF YOUR COMPONENT NEVER RE-RENDERS => USEMEMO JUST DOES NOTHING
	- forces react to do more work on initial render
