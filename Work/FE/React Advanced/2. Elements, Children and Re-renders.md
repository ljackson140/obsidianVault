Basics of reconciliation and diffing?
- React uses shallow comparison for the elements within the component 
- react compares them by reference and not by value
- comparison == true => react will think that this element hasn’t changed thus skip its re-render and as a result re-render of everything inside 
- comparison == false => react will compare the `type` value of that object
	- if the value is the same, react will trigger re-render of the component that is represented by this element   
- scenario: pass the child component as a prop
	- react will skip the re-render of the child and everything inside as the child was created outside of the parent function and its never re-created when the function is called
