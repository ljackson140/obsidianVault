React lifecycle:
- Mounting
	1. Instance - creates components instance for the first time 
	2. State - initializes it’s state, runs its hooks
	3. Dom - Appends element to the DOM
- Unmounting (detects when component is not needed anymore)
	1.  destroys the components instance, its state and all DOM elements in the process 
- Re-rendering 
	- react updates an already existing component with some new data
	- re-rendering is faster than mounting 
	- react uses everything that their already such as the instance, current state etc 
	- every RR starts with the state i.e. user clicks button → triggers update
