### CodeWars Tips:

- If I get a number and I have to calculate them individually I should convert it to string then split it then map it back to a number array:
	- Cannot split a number literal so cast it to a string `.toString()`
	- 
- String Manipulation:
	- use `.split()` to split the string 
	- use `.map` to create a new array with the changed values || map can also be used to select certain properties into a new array
	- use `.charAt()` to find the letter you want to change
