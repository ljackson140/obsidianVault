## Problem solving Framework 
1. Clarify
	- Inputs?
	- Constraints?
	- Edge cases?
2. Brute Force First
	- Always start with brute force 
	- Then optimize 
3. Identify Pattern
	- Repeated work? → DP
	- Order matters? → Sliding Window / Two Pointers
	- Top K? → Heap
	- Parent/child? → Tree
	- Connectivity? → Graph
4. Optimize 
	- Reduce time 
	- Reduce Space
	- Explain tradeoffs 

## How You should Practice LeetCode
❌ Don't do 10 random problems 
✅ Do 3 problems deeply

For each problem:
1. Try yourself for 20-30mins
2. If stuck:
	- Read hints (not solution)
3. If still stuck:
	- Read solution
	- Reimplement without looking 
4. Write:
	- why this works 
	- when to reuse this pattern
