- static web apps are commonly built using libraries and grameworks such as react, angular, vue and more where server side rendering is not required 
- static web apps, are separated from a traditional web server and are instead served from points geographically distributed around the world. this distribution makes serving files much faster as files are physically closer to end users. In addition, API endpoints are hosted using serverless architecture, which avoids the need for a full back-end server altogether
